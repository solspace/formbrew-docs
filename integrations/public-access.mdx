# Tokens and origins

Every definition request and submission is checked against the token, form status, and request origin.

## Public tokens

A public token identifies one form and is part of the public URL:

```text
GET  https://api.staging.formbrew.com/v1/forms/YOUR_PUBLIC_TOKEN
POST https://api.staging.formbrew.com/v1/forms/YOUR_PUBLIC_TOKEN/submit
```

Tokens are publishable and can appear in source HTML, browser bundles, and network requests. Do not treat them like account passwords. Revoke a token to disable integrations using that specific value.

## Allowed origins

An origin is the combination of scheme, hostname, and non-default port:

```text
https://www.example.com
http://localhost:5173
```

The API checks the browser's `Origin` header and falls back to the origin part of `Referer` only when `Origin` is absent. The exact normalized origin must appear in the form's allowed-origin list.

Allowed origins are an abuse-control boundary, not authentication. A non-browser HTTP client can set an origin header itself.

## Browser requests

Do not manually set `Origin` in browser JavaScript. Browsers control that forbidden header. Add the website to the dashboard and let the browser send it.

Formbrew's CORS layer allows public `GET`, `POST`, and `OPTIONS` requests with `Content-Type`. The form-specific allowlist is checked after CORS processing.

## Server requests

Set the intended configured website origin explicitly:

```ts
const client = createFormbrewClient({
  baseUrl: "https://api.staging.formbrew.com/v1",
  token: process.env.FORMBREW_TOKEN!,
  origin: "https://www.example.com",
});
```

With raw HTTP, send the same value in `Origin`:

```bash
curl https://api.staging.formbrew.com/v1/forms/YOUR_PUBLIC_TOKEN \
  --header 'Origin: https://www.example.com'
```

## Troubleshoot origin failures

| Problem | Check |
| --- | --- |
| Production works but staging fails | Add the staging hostname separately |
| Local requests fail | Add the exact localhost scheme and port |
| `www` fails | Add both apex and `www` origins if both serve the form |
| Request sends `Origin: null` | Serve the page over HTTP(S), not a local file or sandboxed context |
| Server request fails | Set `origin` in the SDK or `Origin` in raw HTTP |
