## Before you integrate

Your form needs all three public-access requirements:

1. **Allowed origin** matching the website that loads and submits the form. Add it in **Public access**.
2. **Published status** so the Public API can load the form. You can publish only after you add at least one allowed origin.
3. **Active public form token** used in the embed, endpoint, or SDK configuration. Generate it in **Public access**.

Open **Integration** in the form builder navigation to see the integration guide. It shows whether the form meets these requirements and lets you copy examples with your selected token and current field markup.

## Fastest setup

Load the hosted embed script once, then place a `<formbrew-form>` element where the form should appear:

```html
<script
  crossorigin="anonymous"
  defer
  integrity="sha384-G8oDligKJ0/Zuaer1dZfpMa35oQQEi1DNWYXjmSxmteeveZg6dhzTUuG8M8XnEK9"
  src="https://cdn.jsdelivr.net/npm/@formbrew/embed@0.4.0/dist/embed.js"
></script>

<formbrew-form token="YOUR_PUBLIC_FORM_TOKEN"></formbrew-form>
```

The embed fetches the current definition, renders the fields, includes the honeypot, validates values, submits in place, and displays the configured success message. See [hosted embed](/integrations/embed) for events, theming, and Content Security Policy guidance.

## Verify the integration

Test from the actual website or local development origin you added in the dashboard.

1. Open the browser developer tools and reload the page.
2. Confirm `GET /v1/forms/YOUR_PUBLIC_FORM_TOKEN` returns `200`.
3. Submit valid values.
4. Confirm `POST /v1/forms/YOUR_PUBLIC_FORM_TOKEN/submit` returns `201`.
5. Open **Submissions** in the dashboard and confirm the entry appears.

{/* docs-check: production-setting email.delivery */}

Formbrew stores each test submission, which triggers any email notifications and webhooks configured for the form.

## Common first-run errors

| Status | Cause | Fix |
| --- | --- | --- |
| `401` | Token is revoked or expired | Select or generate an active token |
| `403` | Website origin is missing or not allowed | Add the exact scheme, hostname, and port |
| `404` | Token is unknown or the form is not published | Publish the form and verify the token |
| `400` | Submitted values fail field validation | Read the response `message` and check the field configuration |
| `429` | Request rate limit was exceeded | Stop retries and try again later |

See [troubleshooting](/integrations/troubleshooting) for diagnosis steps and the complete list of error codes.

<Tip>
  For local development, add your exact dev-server origin, such as `http://localhost:5173`. `localhost` with another port is a different origin.
</Tip>
