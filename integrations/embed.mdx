---
title: "Hosted embed"
description: "Render and submit a managed Formbrew form with one script tag."
---

The hosted embed is a version-pinned browser script from jsDelivr. It registers the `<formbrew-form>` custom element, which renders a managed form into your page. The form uses light DOM rather than an iframe or shadow DOM, so your site's CSS can theme it.

## Add a form

Load the script once, then place a `<formbrew-form>` element wherever a form should appear:

```html
<script
  crossorigin="anonymous"
  defer
  integrity="sha384-G8oDligKJ0/Zuaer1dZfpMa35oQQEi1DNWYXjmSxmteeveZg6dhzTUuG8M8XnEK9"
  src="https://cdn.jsdelivr.net/npm/@formbrew/embed@0.4.0/dist/embed.js"
></script>

<formbrew-form token="YOUR_PUBLIC_FORM_TOKEN"></formbrew-form>
```

- The script can load before or after the elements.
- One page can contain several `<formbrew-form>` elements.
- The script also loads its version-matched stylesheet.
- The website origin must be an [allowed origin](/integrations/public-access#allowed-origins) for the form.

Keep the exact package version and integrity hash together. Do not replace the version with a range or a dist-tag such as `latest`. When you upgrade, update the URL and the integrity value at the same time.

| Version | Script URL | Integrity |
| --- | --- | --- |
| `0.4.0` | `https://cdn.jsdelivr.net/npm/@formbrew/embed@0.4.0/dist/embed.js` | `sha384-G8oDligKJ0/Zuaer1dZfpMa35oQQEi1DNWYXjmSxmteeveZg6dhzTUuG8M8XnEK9` |

## Element attributes

| Attribute | Purpose |
| --- | --- |
| `token` | Required public form token. |
| `base-url` | Optional Public API base URL. Defaults to `https://api.formbrew.com/v1`. |
| `data-formbrew-state` | Read-only state set by the element: `loading`, `ready`, or `error`. |

Changing `token` or `base-url` reloads the form. Removing the element from the page aborts its active request and destroys the form. Adding it back renders the form again. This lets frameworks that create and remove elements, such as client-side routers, use the element directly.

A missing `token` renders an error message in the element and emits `formbrew:error` with a `ConfigurationError`.

## Script attributes

| Attribute | Purpose |
| --- | --- |
| `data-formbrew-styles="false"` | Prevents automatic stylesheet loading. |
| `data-formbrew-styles-url` | Loads styles from a custom URL instead of the version-matched stylesheet. |

If you disable automatic styles, keep the honeypot visually hidden. The stylesheet hides it with the `.fb-honeypot` class. You can load the same stylesheet yourself with Subresource Integrity:

```html
<link
  crossorigin="anonymous"
  href="https://cdn.jsdelivr.net/npm/@formbrew/embed@0.4.0/dist/styles.css"
  integrity="sha384-NkoQWlLBtZtH5/3M6oIv6fu/w3aTwIPrLMh74tDj933AUk4wIK39Qd9wh0NbKWwM"
  rel="stylesheet"
/>
```

## Listen for events

Each `<formbrew-form>` element emits bubbling lifecycle events. `event.target` is the element that emitted the event.

```js
document.addEventListener("formbrew:ready", (event) => {
  console.log("Loaded", event.detail.definition.name);
});

document.addEventListener("formbrew:success", (event) => {
  console.log("Submission", event.detail.result.id);
});

document.addEventListener("formbrew:error", (event) => {
  console.error(event.detail.phase, event.detail.error.code, event.detail.error.message);
});
```

| Event | `detail` |
| --- | --- |
| `formbrew:ready` | `definition` and `controller` |
| `formbrew:success` | `result` (`id` and `message`) and `controller` |
| `formbrew:error` | `error` (a `FormbrewError`) and `phase`, either `load` or `submit` |

The controller exposes `reset()` and `destroy()`. A failed load sets `data-formbrew-state="error"` and does not emit `formbrew:ready`.

## Imperative rendering

Call the `Formbrew.render()` global when your code controls where and when the form appears, or when you need to attach submission metadata. Because the script uses `defer`, wait for `DOMContentLoaded`:

```html
<div id="contact-form"></div>

<script>
  document.addEventListener("DOMContentLoaded", () => {
    Formbrew.render("#contact-form", {
      token: "YOUR_PUBLIC_FORM_TOKEN",
      metadata: () => ({ source: window.location.pathname }),
      onSuccess(result) {
        console.log(result.message);
      },
      onError(error) {
        console.error(error.code, error.message);
      },
    }).then((controller) => {
      // Keep the controller if this view later needs reset() or destroy().
      window.contactForm = controller;
    });
  });
</script>
```

`Formbrew.render(target, options)` accepts a CSS selector or an element. Its options are `token`, `baseUrl`, `metadata`, `onSuccess`, `onError`, and `signal`. It returns a promise that resolves to the controller.

Imperative rendering does not emit `formbrew:*` events. Use the callbacks instead:

- `onError` runs for submission errors.
- A load failure rejects the returned promise and shows an error message in the target.

The `<formbrew-form>` element does not accept metadata. Use `Formbrew.render()` or a Hidden field when you need to record integration context.

TypeScript projects that call the browser global can install `@formbrew/embed` as a development dependency and add `import type {} from "@formbrew/embed/global";` for its declarations.

## Theme the form

Override Formbrew CSS variables on the generated form:

```css
formbrew-form .fb-form {
  --fb-accent: #176247;
  --fb-accent-strong: #0f4d38;
  --fb-border: #c9d8d1;
  --fb-danger: #b42318;
  --fb-focus: #78c6a8;
  --fb-muted: #5f6f67;
  --fb-radius: 0.5rem;
  --fb-surface: #ffffff;
  --fb-text: #17201c;
}
```

The generated markup uses stable `fb-*` class names. For imperative rendering, scope the variables to your target element, such as `#contact-form .fb-form`.

## Content Security Policy

A strict Content Security Policy must allow:

| Directive | Source |
| --- | --- |
| `script-src` | `https://cdn.jsdelivr.net/npm/@formbrew/embed@0.4.0/dist/embed.js` or `https://cdn.jsdelivr.net` |
| `style-src` | `https://cdn.jsdelivr.net/npm/@formbrew/embed@0.4.0/dist/styles.css`, `https://cdn.jsdelivr.net`, or your custom stylesheet URL |
| `connect-src` | `https://api.formbrew.com` |

If the script tag has a `nonce`, the loader copies it to the stylesheet link it inserts. The automatically inserted stylesheet link has no `integrity` attribute. To pin the stylesheet with Subresource Integrity, set `data-formbrew-styles="false"` and add the stylesheet link shown above.

Imperative rendering also needs a way to run your inline call to `Formbrew.render()`, such as a nonce or a script file allowed by `script-src`.

## Limitations

- The embed does not support file uploads.
- After a successful submission, the form shows the configured success message in place. There is no redirect option.
- `<formbrew-form>` has no metadata attribute.
