## The basic workflow

1. Sign in at [formbrew.com](https://formbrew.com) and open a workspace.
2. Create a form and add fields in the dashboard.
3. Add an allowed origin for every website that will load or submit the form.
4. Generate a public form token and publish the form.
5. Connect the form using the integration method that fits your frontend.
6. Review submissions in the dashboard or forward them with signed webhooks.

<Note>
  Public form tokens are publishable identifiers. They can appear in browser code. The form's publication status and allowed origins also restrict access.
</Note>

## Work with your team

Forms belong to a workspace. You can create several workspaces and switch between them. Each workspace has an owner and can have members with different roles. See [Workspaces](/dashboard-guide/workspaces) and [Members and roles](/dashboard-guide/members).

## Integration options

| Method | Best for | Rendering |
| --- | --- | --- |
| Hosted embed | Fastest no-build setup | Formbrew renders and manages the form |
| Plain HTML | Sites that should work without JavaScript | You own the markup |
| JavaScript SDK | Framework-neutral applications | Managed or fully custom |
| React SDK | React 18.2 and React 19 applications | Managed component, hooks, or slots |
| Public API | Custom clients and server-side workflows | Fully custom |
