title: "Dashboard quickstart"
description: "Create, publish, connect, and test your first Formbrew form."
---

This guide takes a form from an empty draft to a working frontend integration.

<Steps>
  <Step title="Open a workspace">
    Sign in at [formbrew.com](https://formbrew.com). Choose a workspace, or create one if you have none. See [Workspaces](/dashboard-guide/workspaces).
  </Step>
  <Step title="Create a form">
    Open **Forms** and select **New form**. Formbrew creates an **Untitled form** draft and opens the form builder. Update the name and other form settings in the **Settings** panel.
  </Step>
  <Step title="Add fields">
    Select field types under **Available fields**. Configure each field's label, key, required state, and validation in the **Edit field** panel. Drag fields in the preview to arrange them.
  </Step>
  <Step title="Save your changes">
    Select **Save changes**, or press ⌘S on macOS or Ctrl + S on other systems. The builder keeps your changes as a draft until you save.
  </Step>
  <Step title="Allow your website">
    Open **Public access** and add the exact allowed origin of your website. Include the scheme and port when applicable, for example `https://www.example.com` or `http://localhost:5173`. Select **Save changes**.
  </Step>
  <Step title="Generate a token">
    In **Public access**, select **Add new access token**. Give the token a recognizable name and select **Generate token**.
  </Step>
  <Step title="Publish the form">
    Open **Layout** and select an empty area of the preview to show **Settings**. Change **Status** to **Published** and select **Save changes**. You cannot publish a form until it has at least one allowed origin.
  </Step>
  <Step title="Connect and test">
    Select **Integration**, choose **Embed**, **HTML**, **JavaScript**, or **React**, and copy the generated example. Submit a test entry from an allowed website and verify that it appears under **Submissions**.
  </Step>
</Steps>

<Warning>
  Changes to a published form affect its public definition immediately after you save them. There is no separate republish step.
</Warning>

## Form defaults

New forms start with these values:

| Setting | Default |
| --- | --- |
| Name | `Untitled form` |
| Status | Draft |
| Submit button | `Submit` |
| Success message | `Thanks for your submission.` |
| Honeypot | A generated name such as `_fb_k3m9x2q7_url` |

Continue with [Manage forms](/dashboard-guide/forms) for form lifecycle details or [Fields](/dashboard-guide/fields) for every supported field type.
