# Manage forms

The **Forms** page lists every active draft and published form in your workspace. Each card shows the form name, status, field count, and actions to edit or archive it.

## Create a form

Select **New form**. Formbrew immediately creates a draft and opens its layout editor. There is no setup dialog, so configure the form in the settings panel after it opens.

## Form settings

Click an empty area of the preview, or click the preview submit button, to show form settings.

| Setting | What it controls |
| --- | --- |
| Name | The internal and public form name. It is required. |
| Slug | A workspace-unique, URL-friendly identifier. Formbrew lowercases it and replaces unsupported characters with hyphens. |
| Status | `Draft` prevents public access. `Published` enables the public definition and submission endpoints. |
| Submit button | The label used by managed Formbrew renderers. An empty value becomes `Submit`. |
| Honeypot input name | The anti-spam field name used by managed and manual forms. |
| Success message | The message returned after an accepted submission. |

The honeypot name must start with `_`, contain 4 to 80 letters, numbers, underscores, or hyphens, and must not collide with a normal field key.

<Note>
  Editing the form name in the dashboard also regenerates its slug. Set the final name first, then customize the slug if needed.
</Note>

## Draft and published forms

Draft forms cannot be fetched or submitted through the public API. To publish a form:

1. Add at least one allowed origin under **Public access**.
2. Make sure every field has valid settings.
3. Set **Status** to **Published**.
4. Select **Save**.

A form can remain published while you edit fields, labels, validation, button text, and success text. Integrations fetch the current definition, so saved changes can affect visitors immediately.

## Archive a form

Select **Archive** on a form card to remove it from the active list and disable normal management access. Archiving is immediate, with no confirmation or restore workflow in the current dashboard.

<Warning>
  Treat archive as irreversible from the dashboard. Make sure you no longer need to manage the form before archiving it.
</Warning>
