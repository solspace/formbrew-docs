# Usage

The **Usage** page shows accepted public submissions for the current UTC calendar month.

| Value | Meaning |
| --- | --- |
| Current period | The first day of the current UTC month through the first day of the next month |
| Submissions received | Public submissions accepted during that period |

Usage is recorded when a submission is stored successfully. Rejected validation, origin, honeypot, and rate-limit requests do not count as accepted submissions.

Plans, billing limits, invoices, payment controls, and historical usage charts are not available yet. The current counter preserves usage history for future plan and limit support.
